# 4_main analysis

This directory contains per-trajectory and censored ensemble analysis for the retained 0.5 fs production campaign.

- 51 trajectories contribute through 30 fs.
- `traj_004` contributes through its final valid frame at 16 fs.
- `total/1_segment_30fs/available_trajectories.png` reports ensemble attrition.
- `total/1_segment_30fs/trajectory_status.csv` records completion and censoring.
- Means after 16 fs contain 51 surviving trajectories and may underestimate dissociation if failure correlates with difficult geometries.
- `total/2_add1/` contains the 51-trajectory update; `traj_051` is highlighted in red in `individual_coordinates.png`.
- `total/3_add2/` contains the 52-trajectory update; `traj_052` is highlighted in red in `individual_coordinates.png`.
